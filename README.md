# 🎵 Color Sound (WIP)

[Experimente Online](https://rotinom0.github.io/color-sound/)

Sistema de visualização de som feito com React.js e JavaScript que transforma áudio em experiências visuais interativas.

## ✨ Funcionalidades

- Visualização em tempo real de áudio
- Análise de frequências sonoras
- Efeitos visuais dinâmicos baseados em cores

## 🚀 Tecnologias

- **React** - Biblioteca JavaScript para interfaces
- **Vite** - Build tool e dev server
- **Web Audio API** - Processamento de áudio no navegador
- **Canvas API** - Renderização de gráficos

## 📋 Pré-requisitos

- Node.js (versão 16 ou superior)
- npm ou yarn

## 🔧 Instalação
```bash
# Clone o repositório
git clone https://github.com/rotinoM0/color-sound.git

# Entre no diretório
cd color-sound

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

## 🎮 Como usar

1. Abra o navegador em `http://localhost:5173`
2. Permita o acesso ao microfone quando solicitado
3. Faça sons ou reproduza música para ver a visualização

## 📦 Build para produção
```bash
npm run build
```

Os arquivos otimizados estarão na pasta `dist/`.
